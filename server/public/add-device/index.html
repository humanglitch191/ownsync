Not yet? Install it first

  1. Install Obsidian and open (or create) the vault you want to sync.
  2. In Obsidian, open Settings → Community plugins and turn them on.
  3. Choose Browse, search for Ownsync (or open it directly), then Install and Enable.
  4. Scan the code on your other device again: it shows a fresh one every 2 minutes.
